# SignService — подписание документов ЭЦП

Отдельное настольное приложение на C# / [Avalonia UI](https://avaloniaui.net/) для подписания
документов электронной подписью (ЭЦП). Логика подписания повторяет сервис подписания
документов из ReportGGE: сертификаты берутся из хранилища пользователя, подпись
формируется в формате CMS/PKCS#7 (CAdES-BES).

## Возможности

- **Drag & drop** — перетащите файлы (или целые папки) прямо в окно программы;
- **Обзор** — добавление файлов через стандартный диалог выбора;
- выбор сертификата подписи из хранилища текущего пользователя («Личное»);
- **откреплённая** подпись — рядом с документом создаётся файл `имя_файла.sig`
  (формат, который требуют госпорталы и большинство систем документооборота);
- **прикреплённая** подпись — документ упаковывается внутрь `.sig`;
- пакетное подписание: очередь файлов со статусом по каждому файлу;
- фильтр просроченных сертификатов.

## Требования

- .NET 8 SDK (для сборки) / .NET 8 Desktop Runtime (для запуска);
- Windows с установленным криптопровайдером для ГОСТ-сертификатов
  (например, **КриптоПро CSP**) — подпись квалифицированной ЭЦП выполняется
  через CSP, привязанный к контейнеру закрытого ключа; при подписании может
  появиться системный диалог ввода PIN-кода;
- на Linux/macOS приложение также работает, но подписывает только сертификатами
  с алгоритмами, поддерживаемыми платформой (RSA/ECDSA); ГОСТ-криптография
  доступна только через CSP на Windows.

## Сборка и запуск

```bash
dotnet build SignService.sln -c Release
dotnet run --project src/SignService
```

Публикация самодостаточного exe для Windows:

```bash
dotnet publish src/SignService -c Release -r win-x64 --self-contained -o publish
```

## Как пользоваться

1. Запустите программу — в выпадающем списке появятся сертификаты
   с закрытым ключом из хранилища «Личное» текущего пользователя.
2. Выберите сертификат и режим подписи (откреплённая/прикреплённая).
3. Перетащите файлы в окно или добавьте их кнопкой **«Обзор…»**.
4. Нажмите **«Подписать»** — рядом с каждым файлом появится `имя_файла.sig`,
   статус отобразится в списке.

## Структура проекта

```
src/SignService/
├── Services/
│   ├── CertificateProvider.cs   # доступ к сертификатам (X509Store)
│   └── DocumentSigner.cs        # подпись CMS/PKCS#7 (SignedCms) + проверка
├── ViewModels/
│   ├── MainWindowViewModel.cs   # очередь файлов, команды подписания
│   ├── CertificateItem.cs
│   └── SignFileItem.cs
└── Views/
    └── MainWindow.axaml(.cs)    # UI: drag & drop, обзор, список файлов
```
